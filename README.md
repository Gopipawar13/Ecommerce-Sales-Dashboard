# 📊 E-Commerce Sales Dashboard | Excel Data Analysis Project

## 🔍 Project Overview
This project analyzes an e-commerce dataset using Microsoft Excel and presents key insights through an interactive dashboard.

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Slicers

## 📌 Key Insights
- The Set category generates the highest revenue
- Sales reached their peak in March
- Female customers contribute the largest share of revenue
- The Adult age group is the most active segment
- Maharashtra and Karnataka are top-performing states
- Bengaluru is the top city by orders.
